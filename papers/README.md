# Papers

* `easyresearch/` – EasyResearch: honest regression, forecasting and signal
  classification for researchers who do not program. Build with
  `latexmk -pdf main.tex`. The numbers in `results.tex` and the tables
  `tab_*.tex` are generated by
  `python benchmarks/easyresearch_honesty_report.py --tex-dir papers/easyresearch`.

The EasyClassifier paper is arXiv:2610.04758.
